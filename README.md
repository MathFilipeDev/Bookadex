# Bookadex — Tela Inicial

Este repositório contém a implementação da **tela inicial (landing page)** do projeto acadêmico **Bookadex**, desenvolvida utilizando apenas **HTML e CSS**.

O objetivo deste módulo foi estruturar a interface inicial da aplicação, definindo layout, organização visual e identidade básica do sistema, servindo como ponto de entrada para o projeto completo.

Este repositório representa uma **parte isolada do projeto Bookadex**, enquanto a lógica de negócio e o Back-end foram desenvolvidos e integrados em outro repositório central.

## Tecnologias utilizadas
- HTML5  
- CSS3  

## Contexto
Projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas, com foco na separação de responsabilidades entre interface e lógica de aplicação.
